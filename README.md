# AI Innovation Suite

An advanced AI Command & Intelligence suite built with Angular 18 (Standalone Components & Signals), Tailwind CSS, and Google Gemini 3 API integrations.

## Features
- **22 Official Indian Languages Dynamic Translation**: Instant regional localization powered by Gemini AI API.
- **Voice Navigation & Command System**: Speak "go to chat", "go to vision and select image", etc.
- **Multimodal Vision & Image Studio**: Analyze images with Gemini 3 Flash.
- **Gemini Chat with Google Search Grounding**: Contextual LLM responses with web citation sources.
- **Text-to-Speech Voice Studio**: Real-time audio waveform animation & multi-voice TTS synthesis.

## Quick Start Instructions

1. **Extract ZIP File**:
   ```bash
   unzip ai-innovation-suite.zip
   cd ai-innovation-suite
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm start
   ```

4. Open your browser at `http://localhost:4200`.
