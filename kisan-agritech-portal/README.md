# KisanSetu AI - Smart Agri-Tech Portal

An enterprise-ready, modular Angular 21+ web application built with a high-contrast green-and-white theme tailored for Indian farmers.

## Features
1. **Authentication**: Farmer Login and New Registration with Region and Primary Crop attributes.
2. **Interactive Agricultural Dashboard**: Real-time mandi prices, weather forecasts, and module launchers.
3. **AI Krishi Chat**: Dedicated agronomist consultation for crop diseases, fertilizers, and pest management.
4. **Crop Disease Scanner**: Upload crop/leaf photos or test verified sample specimens with confidence scores, cures, and prevention tips. Supports the command input (e.g., "go to dashboard").
5. **Hands-free Voice Assistant**: Speech recognition and synthesis supporting hands-free navigation across Indian state languages.
6. **All 12 Major Indian Regional Languages**: Seamless translation for English, Hindi, Odia, Bengali, Telugu, Tamil, Marathi, Gujarati, Kannada, Malayalam, Punjabi, and Assamese.

## Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm start
```

Open your browser at http://localhost:4200 to experience the portal.
